# Models and simulations

Application-specific models and simulations used by the Ukraine paper belong here.

A model should state:

- which real-world feature it is intended to represent;
- assumptions and simplifications;
- inputs and outputs;
- the hypothesis or mechanism it tests;
- whether the result is analytical, exact computational evidence, numerical
  simulation, or exploratory;
- what empirical claim it does **not** establish.

Reusable theorem development and general mathematical provenance do not belong in
this directory.
