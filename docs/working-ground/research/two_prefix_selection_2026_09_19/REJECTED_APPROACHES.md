# Rejected approaches and remaining uncertainty

- **Try to prove NP-hard segment order selection.** R09 had only an NP upper bound;
  Helly and move-to-front now give polynomial selection. A hardness claim for this
  exact rational-segment problem would imply P=NP. No false lower bound was published.
- **One permanently blocking sender must suffice.** R08's changing-blocker segment
  has no successful singleton prefix but has a successful pair. Exact witnesses
  for each singleton are retained, with a continuum proof for the pair.
- **Two senders suffice in every convex uncertainty family.** False. The explicit
  n=4,d=2 triangle needs a three-prefix. The n=5,d=3 hull also defeats a universal
  three-prefix bound. These are the same strategic model with admissible parameters.
- **All rejected pairs share one bad model.** False as an inference. The inherited
  two-sender modelwise-success/no-common-order example supplies separate witnesses;
  the selector records them independently.
- **A root/sample grid is an exact decision method.** Rejected. A cell can be narrower
  than 10^-29; repeated roots and endpoint ties matter. Exact root counts, complete
  cell coverage and rational sign substitution are used instead.
- **Benchmark time proves polynomial bit complexity.** Rejected. Fast polynomial
  complexity follows from established algebraic algorithms; local elementary Sturm
  performance is a separate measured fact.
- **The failed dimension-four search improves the bound.** Unsupported. Twenty
  prefixes lack found witnesses in that search, which is not an exact infeasibility
  result. General sharpness remains open, not disproved.
- **This is new Helly/optimization/game theory.** Unclaimed. Borrowed mathematical
  machinery is explicit; historical priority of this particular application is open.
