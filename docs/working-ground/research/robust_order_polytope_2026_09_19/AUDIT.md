# Author completion audit

## Exact subject and guarantee

Subject: R08's sequential complementary-evidence game under a compact convex set
of independent-bit probability parameters. One institutional order and fine must
work for every compatible p, with model-dependent equilibria and favorable ties.
Operation: certify a common zero-fine order, or conclude that every order requires B.
Theorem T1 characterizes feasibility by weights; T2 makes a supplied-order polytope
certificate finite. This is a characterization, not a polynomial order-finding
algorithm. T8 adds an exact verification complexity bound for rational segments.

Premises include positive costs/rewards, n≥2, nonempty compact P⊂(0,A/(A+B))^n,
players knowing the actual p, one receiver, one report opportunity per sender,
authenticated positive-only certificates, the AND objective and a receiver fine.
The model's independence is within EACH p; the uncertainty coordinates are jointly
constrained. Conflating these two levels would invalidate the interpretation.

## Aggressive tests and remaining gaps

Vertex evaluation is false, but finite vertex SUPPORT certificates are valid.
Pairwise feasible regions suffice at n=3 but fail at n=4. A simple greedy rule
fails, while stable modelwise scores earn a restricted greedy theorem. Successful
orders are not generally ordinary poset/antimatroid/greedoid words. Deterministic
message-adaptive ordering adds no value in the declared AND benchmark.

NP-hardness is unresolved, not disproved. Exact arbitrary-polytope bit complexity,
complete structural order selection, and hidden future randomization remain open.
No all-game necessary/sufficient adaptation criterion is claimed. The requested
minimum positive fine is exactly B within this benchmark; deriving a smooth
positive-fine frontier would require changing the game, not more optimization.

The former R08 experiment summary contains no executable to replay. This run uses
new independent source and receipts, not invented historical evidence. Existing
source retrieval gaps remain gaps. The source audit does not certify novelty.

## Research decision

Retain the central question. Verification and information retention have advanced;
order selection is still a substantive unsolved part. Next attack: decide whether
variable-n rational-segment common-order selection is polynomial or NP-hard.
The precise upper bound and counterexamples make that question more focused,
without changing to arbitrary evidence systems or an unrelated network programme.
