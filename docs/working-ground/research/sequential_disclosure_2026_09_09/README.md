# Sequential disclosure and compatible uncertainty

Research phase dated **September 9, 2026**.

This phase follows the optimized-gate/recovery work and returns to the central
composition question: what shared information constraints must be retained to
calculate the enforcement needed to sustain a fixed arrangement?

The investigation first audited the closest multi-sender persuasion,
information-plus-incentive and disclosure literatures. It then rejected two
tempting routes: a generic "multi-sender implementability" novelty claim and a
simultaneous all-silent rank-one obstruction. The surviving direction is
sequential hard evidence under analyst uncertainty about local information
conditions.

## Main result

For a complementary-evidence game with sequential disclosure, the phase derives
an exact minimum-fine formula for any disclosure order. It then gives a
three-sender example in which preserving one shared restriction on uncertain
local probabilities makes **zero** enforcement sufficient, while replacing that
restriction by the same separate local ranges raises the robust minimum to
**one**, even after optimizing over every sequential order.

This is a bounded result and candidate paper direction, not an established
novelty claim.
