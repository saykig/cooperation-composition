# Methods

Research design and operationalization for the application paper.

Use this directory to specify:

- the unit of analysis;
- case-selection logic;
- variables/constructs and how they are observed;
- how mathematical quantities, if used, map onto the empirical case;
- simulation design and what it can and cannot test;
- robustness checks and alternative explanations.

The mathematical foundation may constrain a method once a result is actually
selected, but the dependency is not fixed yet.
