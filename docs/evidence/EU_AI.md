# EU AI: documentation access beyond signing a code

Reviewed 21 September 2026. Labels follow the [methods note](../methods/EMPIRICAL_INFERENCE.md); sources and retrieval limits are in the [manifest](SOURCES.md). No mathematical dependency is assumed.

**INFERENCE — bounded question:** do downstream providers actually receive usable capabilities/limitations information through GPAI documentation channels? The initial unit is a model-version/documentation-request episode, not a company signature. Review the July 2025 implementation framework through 21 September 2026.

## Evidence map

| Dimension | Evidence and status |
|---|---|
| Actors | **FACT:** the legal framework distinguishes model providers, downstream system providers, the AI Office and national authorities. [A1](SOURCES.md#a1). |
| Decision | **HYPOTHESIS:** a downstream firm decides whether and how to integrate a model, while the upstream firm decides what information to release. No named downstream integration decision is established in this corpus. |
| Target arrangement | Timely, sufficient documentation for downstream assessment and oversight; assess sufficiency against the recipient's task, not volume of published pages. |
| Who knows what | **INFERENCE:** upstream firms have privileged access to training/evaluation records; downstream firms know their application setting. Public opacity alone does not show that private recipients lack information. |
| Disclosure/withholding/transformation | **FACT:** Google exposes a contact mechanism for model-documentation inquiries from authorities and downstream providers, referring to Code Measure 1.2. [A4](SOURCES.md#a4). **UNKNOWN:** responses, redactions, eligibility decisions or delays. |
| Incentive or deviation | **HYPOTHESIS:** protecting commercial information, avoiding liability or saving documentation costs may favour selective disclosure. Genuine security constraints and imperfect knowledge can produce the same pattern. |
| Institutional instrument | **FACT:** Article 53 and Annexes XI/XII distinguish authority-facing and downstream duties, with qualifying exemptions; the Code offers a voluntary compliance route. [A1](SOURCES.md#a1), [A3](SOURCES.md#a3). A signature is not a regulatory finding. |
| Observable outcome | Contact interface exists; independent research measures uneven public transparency. **UNKNOWN:** whether this channel changes downstream decisions or satisfies legal duties. [A4](SOURCES.md#a4), [A5](SOURCES.md#a5). |
| Strongest rival | **HYPOTHESIS:** privacy/security, legitimate confidentiality, release timing and immature documentation practices explain observed omissions without strategic evasion. |
| Primary records | Law; Commission FAQ; Code and signatory list; Google inquiry interface. The linked Code PDF failed retrieval in this pass: no unverified response-deadline claim is adopted. |
| Independent corroboration | Wan et al.'s FMTI evaluates public disclosure; Euronews records Meta's public opposition to signing. Neither independently observes a downstream request/response. [A5](SOURCES.md#a5), [A6](SOURCES.md#a6). |
| Inaccessible evidence | **UNKNOWN:** confidential documentation, recipient correspondence, actual regulator submissions, refusal reasons, trade-secret assessments and enforcement case files. |
| Causal inference | **Plausible** descriptive document audit; **weak** mechanism inference until one contested request is documented; **impossible with current corpus** to estimate an enforcement-induced compliance effect. |

## What the evidence changes

**SOURCE CLAIM:** the 2025 FMTI reports lower average public-transparency scores than in 2024 and substantial variation across firms. Its indicators and developer coverage changed; neither a raw year-to-year difference nor a low score identifies an AI Act violation. Public summaries, downstream documentation and authority access are distinct information channels. [A5](SOURCES.md#a5).

**FACT:** the Commission's current list includes different chapter participation, including xAI's safety/security-only signature. **INFERENCE:** a binary signed/unsigned variable would misclassify institutional exposure. Meta's refusal reported in July 2025 is evidence of contestation, not evidence of illegal nondisclosure. [A3](SOURCES.md#a3), [A6](SOURCES.md#a6).

**SOURCE CLAIM:** Commission guidance distinguishes the August 2025 application date, August 2026 enforcement stage and August 2027 deadline for models already marketed before August 2025. [A2](SOURCES.md#a2), [A7](SOURCES.md#a7). Code signature, launch date, applicable exemption and document recipient must be coded separately. The searched sources did not establish a named GPAI downstream-documentation enforcement outcome; this is a retrieval limit, not a claim that none exists.

## Discriminating next evidence

Select two named model versions with known EU market dates. Compare public documentation with Annex XII fields and record availability separately from adequacy. Seek an already public downstream request, response/refusal and resulting integration decision. Without that chain, narrow to implementation architecture and disclosure gaps; do not call the case strategic noncompliance or use global transparency rankings as a regulatory treatment effect.
