# Evidence

Empirical evidence for the Ukraine-focused paper belongs here.

For each important source or factual claim, preserve:

- what the source directly establishes;
- date and relevant time period;
- whether the source is primary, official, journalistic, academic, or analytical;
- any uncertainty or contestation;
- which hypothesis or part of the argument it informs.

Do not treat a mathematical result, simulation, or model output as empirical
evidence about Ukraine.
